1. Откройте http://localhost:3000
2. Нажмите **"Демо-вход"**
3. ✅ Должны попасть на **Dashboard** (не на онбординг)

   - ✅ Кнопка "Начать урок" активна
   - ✅ В шапке: "Русский → English • B1"

1. Откройте http://localhost:3000
2. Нажмите **"Нет аккаунта? Зарегистрироваться"**
3. Введите email и пароль
4. Нажмите **"Зарегистрироваться"**
5. ✅ Должны попасть на **Онбординг**

#### Онбординг — Шаг 1: Родной язык
6. ✅ В списке должен быть **Russian (Русский)** первым
7. Выберите "Russian"
8. Нажмите **"Далее"**

#### Онбординг — Шаг 2: Изучаемый язык
9. ✅ Русский НЕ должен быть в списке (нельзя учить родной язык)
10. Выберите "English"
11. Нажмите **"Далее"**

#### Онбординг — Шаг 3: Уровень
12. Выберите "B1"
13. Нажмите **"Далее"**

#### Онбординг — Шаг 4: Интенсивность
14. Выберите "Стандартный"
15. Нажмите **"Начать обучение"**
16. ✅ Должны попасть на **Dashboard**

### Сценарий 3: Проверка русского языка в настройках

1. На Dashboard нажмите иконку **Settings** (⚙️)
2. ✅ В выпадающем списке "Родной язык" должен быть **Russian (Русский)**
3. ✅ В выпадающем списке "Изучаемый язык" должен быть **Russian (Русский)**

2. Войдите снова через "Демо-вход"
3. ✅ Должны попасть на **Dashboard** (не на онбординг)
4. ✅ Данные сохранены (streak, статистика)

## 🐛 Если что-то не работает

### Проблема: После "Демо-вход" остаюсь на странице логина

**Решение:**
1. Очистите localStorage:
   ```javascript
   localStorage.clear()
   ```
2. Перезагрузите страницу (F5)
3. Попробуйте снова

### Проблема: После онбординга не перехожу на Dashboard

**Решение:**
1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что `navigate` импортирован в `OnboardingPage.tsx`:
   ```typescript
   import { useNavigate } from 'react-router-dom';
   ```
3. Пересоберите проект:
   ```bash
   npm run build
   ```

### Проблема: Русский язык не отображается в списке

**Решение:**
1. Проверьте `src/store.tsx` — массив `LANGUAGES` должен содержать:
   ```typescript
   { code: 'ru', name: 'Russian', nativeName: 'Русский' }
   ```
2. Перезапустите dev-сервер:
   ```bash
   npm run dev
   ```

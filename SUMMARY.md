# LinguaFlow — Сводка проекта

## 🎯 О проекте

**LinguaFlow** — веб-приложение для изучения иностранных слов методом интервального повторения в контексте предложений.

**Ключевая особенность:** слова изучаются не изолированно, а в составе осмысленных предложений, сгенерированных AI с учётом уровня пользователя и выбранной тематики.

---

## 🏗️ Архитектура

```
Frontend (React) → Backend (FastAPI) → PostgreSQL
                              ↓
                    ┌─────────┼─────────┐
                    ↓         ↓         ↓
                GigaChat   Silero TTS   FSRS
                 (LLM)      (TTS)    (алгоритм)
```

### Компоненты

1. **Frontend** — React + TypeScript + Tailwind CSS
2. **Backend** — FastAPI + Python 3.11
3. **Database** — PostgreSQL 14+
4. **LLM** — GigaChat API (Сбер)
5. **TTS** — Silero TTS (локальная, бесплатная)
6. **Algorithm** — FSRS-4.5 (интервальное повторение)

## 📊 Функциональность

### Для пользователей

1. **Регистрация и онбординг**
   - Выбор родного и изучаемого языка
   - Выбор уровня (CEFR A1-C2)
   - Настройка интенсивности обучения

2. **Дашборд**
   - Статистика (streak, слова, прогресс)
   - Слова на повторение сегодня
   - Быстрый старт урока

3. **Уроки**
   - Выбор тематики (еда, путешествия, работа, семья)
   - Прослушивание предложения (TTS)
   - Перевод предложения целиком
   - AI-оценка каждого слова
   - Разбор результатов

4. **Словарь**
   - Добавление пользовательских слов
   - Просмотр прогресса по словам
   - Детали FSRS (stability, difficulty)

5. **Статистика**
   - Графики активности
   - Распределение слов (новые/в процессе/закреплено)
   - История уроков

6. **Настройки**
   - Изменение языковой пары
   - Настройка интенсивности
   - Управление подпиской

### Технические возможности

- **Кэширование предложений** — повторное использование сгенерированных
- **Кэширование аудио** — TTS генерируется один раз
- **FSRS алгоритм** — адаптивные интервалы повторения
- **Демо-режим** — frontend работает без backend
- **REST API** — готов для мобильного приложения

## 🗄️ Модель данных

### Основные сущности

1. **User** — пользователь
   - Email, пароль, настройки
   - Языковая пара, уровень
   - Streak, статистика

2. **Word** — слово из тематического списка
   - Текст, перевод
   - Тематика, уровень CEFR

3. **UserWordProgress** — прогресс пользователя по слову
   - FSRS параметры (stability, difficulty)
   - Даты повторений
   - Счётчики (review_count, lapses)

4. **Sentence** — сгенерированное предложение (кэш)
   - Текст, перевод, аудио
   - Целевые слова
   - Метаданные (язык, уровень, тема)

5. **LessonSession** — сессия урока
   - Карточки, результаты
   - Время начала/окончания

6. **LessonAnswer** — ответ пользователя
   - Перевод пользователя
   - Оценка LLM (какие слова верны)

## 💰 Стоимость эксплуатации

### GigaChat API

Для 1000 активных пользователей:
- Генерация предложений: ~5 руб/день
- Оценка переводов: ~250 руб/день
- **Итого: ~7650 руб/месяц**

### TTS (Silero)

- **Бесплатно** — локальная модель
- Требует: 2+ ядра CPU, 2+ GB RAM

### Сервер

- Минимум: 2 CPU, 4 GB RAM, 20 GB диск
- Рекомендация: 4 CPU, 8 GB RAM, 50 GB SSD
- Стоимость: ~1000-3000 руб/месяц (VPS)
